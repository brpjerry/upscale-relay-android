Autoplay is now optional, and the model list has a menu of its own.

**Choose what happens when a video ends (Settings → Player).** "Play the next
video automatically" is on, and behaves exactly as it always has: the next
unwatched file in the same folder starts. Turn it off and a finished video
closes the player and returns you to the library instead, the same as pressing
back. Only a video that genuinely reaches its end does this — a stream that
drops mid-file still belongs to the automatic reconnect, which is unchanged.

**The model picker is its own menu.** A server can publish twenty or more
upscaling models, and they used to sit in a short scrolling box at the top of
the player's Playback settings, showing about five at a time with everything
else pushed below them. There is now a Model button in the player's top bar
that opens the full list at full height, each entry labelled with its scale
factor and opening scrolled to the one you are using. Quality, framing, and
the downscale filter stay where they were. Nothing moved on the Settings
screen.

Both were checked on a Galaxy Tab S9 Ultra against a live relay: a video played
to its end returns to the library with the file marked watched, the same video
with the setting back on advances to the next episode, and the model sheet
lists and applies all twenty models the server offers.

This release is signed with the same key as v0.15.0 through v0.16.4 and
upgrades over them normally. Moving from a locally built debug APK still
requires an uninstall, because debug and release signatures differ — export
your data first.
