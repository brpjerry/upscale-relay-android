This release fixes the ten findings of the October audit and a run of player
problems found on the tablet since. It pairs with Upscale Relay Server
v0.24.0.

**Playback comes back after the tablet sleeps.** Waking the tablet on a paused
video could show "Server did not confirm resource release" and leave nothing
to do but go back to the library. The connection had died while the tablet
slept, so the old session could not confirm that it had shut down, and the app
would not start another behind it. It now asks the server whether that session
has been released, waits for it if it has not (up to a minute), and resumes
where you were. It still stops with that message when the server says the
session is stuck, or that it needs a restart.

**Watch history belongs to the server it was made on.** Progress, watched
marks and recents were kept by file path alone, so two servers with the same
folder layout shared them. They are now kept per server.

- **Your existing server history and recents are not carried over.** The first
  launch of this version starts them fresh. History for files opened from the
  tablet itself is kept.
- With relay server v0.24.0 the history follows a server when its address
  changes. With an older server it is tied to the host and port.
- Older backups still import, without their server history.

**The player**

- **The lock takes one press.** A press that landed slightly off the lock was
  treated as a tap on the picture: the controls vanished and the lock then
  took two more presses. The control bars now take such presses themselves,
  and the lock's touch area runs out to the corner of the screen. While
  locked, a tap on the picture only ever brings the unlock button up.
- On the Galaxy Tab S9 Ultra the tablet itself was cancelling about half of
  the presses on the lock, which sits in the top bar, as palm touches: the
  button lit up and nothing happened. The app now takes a top-bar press that
  was cancelled that way as the press it was.
- **The skip buttons** pressed while an earlier seek was still loading could
  jump to the start of the file. They now move from where you asked to be.
- Pressing one control no longer lights up all of them.
- **The top bar** starts at the top edge, with the notch over its empty
  middle, instead of hanging below a strip of bare picture. The picture is
  full size, as before.
- **The menus** (Audio & subtitles, Model, Playback settings, Chapters) no
  longer bring the status and navigation bars back while they are open.
- The controls stay up for as long as you are dragging the seek bar.
- Swipes for seeking, brightness and volume no longer start from on top of
  the control bars while those are showing; they work from the picture.

**Local files**

- Files with non-square pixels (DVD-style 720x576 and the like) play at their
  intended shape through relay server v0.24.0.
- A file whose video samples begin with a unit of 256 to 511 bytes is now
  sent correctly. It was mistaken for a different packaging and could fail to
  play.
- A file that is slow to prepare, or a slow seek, no longer fails with a
  player connection timeout.
- "Play original" after the relay failed to open a file keeps your place,
  resumes, and handles the end of the file like any other playback.

**Library and settings**

- A video started while the app was still connecting, just after launch or a
  wake, is no longer closed again when that connect completes.
- Going Up while a folder was still loading no longer bounces you back into
  it.
- Changing the sort order of a long folder no longer mixes the old order into
  the pages loaded afterwards.
- Settings shows why a connection failed and marks a host or port that is not
  valid; TalkBack announces the message.
- "Save diagnostic log to Documents" stays on across restarts and is restored
  by a backup.

**Known issues**

- On the Tab S9 Ultra the lock can still occasionally need a second press. In
  one test by hand the tablet flagged 16 presses as palm touches and the app
  delivered 11 of them; the other five are not yet explained. The diagnostic
  log now records why a flagged press was left alone, and a later release
  will follow this up.
- A local file whose storage fails partway through playback ends early
  without an error.

Checked on a Galaxy Tab S9 Ultra against the relay server this release pairs
with: the device regression suite, a Wi-Fi drop under a playing video resuming
on a new session, history kept apart per server, and three anamorphic clips
coming back 4:3. The cancelled lock presses were traced by hand, because
scripted input never passes through the tablet's touch controller.

The version jumps from 0.22.0 to 0.24.0 to match the relay server's numbering;
there is no Android 0.23.

This release is signed with the same key as v0.15.0 onwards and upgrades over
them normally.
