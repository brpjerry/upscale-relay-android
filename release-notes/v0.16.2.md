This maintenance release refreshes the Android build toolchain and runtime
dependencies.

- Kotlin 2.4.10
- Android Gradle Plugin 9.3.1
- Kotlin serialization JSON 1.11.0
- AndroidX Compose BOM 2026.06.01
- AndroidX test JUnit 1.3.0

There are no intentional application behavior changes in this release.

This release is signed with the same key as v0.15.0, v0.16.0, and v0.16.1 and
upgrades over them normally. Moving from a locally built debug APK still
requires an uninstall because debug and release signatures differ; export your
data first.
