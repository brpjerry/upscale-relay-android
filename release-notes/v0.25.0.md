This release brings HDR to the tablet's screen and catches up with Upscale
Relay Server v0.26.0: playback now rides out network dropouts, and the
server buffers as much video as the player's cache holds. It pairs with relay
server v0.26.0; with an older server everything new is simply left off.

**Playback through network dropouts.** A dropout longer than about 10-30 s
used to end playback with "Network connection lost" and start the video over
on a new session, however much was buffered. With relay server v0.26.0 the
video keeps playing from its buffer, a small "Reconnecting to the server…"
note shows in the corner, and the app picks the same session back up once
the server can be reached again. It tries for as long as the server holds the
session (about two and a half minutes) and says nothing while it does. In a
test on the Tab S9 Ultra the connection to the server went silent for 45 s;
playback never stopped and carried on on the same session 2 s after the
network came back. Turning the tablet's Wi-Fi off still restarts the video at
your position, as before: Android closes the video connection along with the
Wi-Fi.

**Cache size.** A new "Cache size" setting (Settings and the player's
settings, 256 MB to 5 GB, 768 MB by default) sets how much video the player
holds in memory ahead of playback. The server keeps it filled, so
lower-bitrate video is buffered further ahead: minutes at the lossy
qualities, where before it was always 10 s. The setting says roughly how long
the cache holds at the chosen quality, and when a server is too old to fill
it. Changing it applies at once, without restarting the video.

**HDR**

- **"Show HDR videos in HDR"** (on by default): on an HDR display, HDR videos
  now play in HDR with 10-bit colour, subtitles at the display's brightness.
  It falls back to tone-mapped SDR with the battery saver on, on an SDR
  display, or with the setting off, and switches at the current position
  when any of those change.
- HDR videos stream at 10 bits, and the server maps Dolby Vision and HDR10+
  for the display they are shown on.
- **"Use 10 bit video"** streams every video at 10 bits: smoother gradients
  and a smaller stream, for more work on the server.
- Local HDR10 files describe their colour and mastering metadata to the
  server, MP4 files included.

**Other changes**

- **"Use passthrough for 4K or higher resolution videos"** streams videos
  3840 wide or 2160 tall and up without the upscale model, leaving your model
  choice alone for everything else.
- A playback setting changed while a video was opening, reconnecting or
  moving to the next file now applies to the video that ends up playing.

Checked on a Galaxy Tab S9 Ultra against relay server v0.26.0: a 45 s
dropout of the control connection ridden out on the same session, a Wi-Fi
drop reopening at the same position, and the buffer target confirmed and
applied by the server.

This release is signed with the same key as v0.15.0 onwards and upgrades over
them normally.
