Recovery that retries before it complains, one loading affordance across the
app, gestures that stay on the control you started, autoplay that skips what
you have already watched, and backup/restore for everything the app saves.

**Sleep and wake no longer greets you with an error.** Closing the tablet on
the library screen drops the control socket within seconds — Wi-Fi power save
kills it once no playback service is holding a lock. The client used to raise
the failure immediately and leave the banner up. It now defers: the failure is
held while the app is in the background and retried the moment you come back,
so opening the tablet reconnects on its own and reopens the directory you were
in. The same applies during playback — a session that dies while you are away
resumes at the position it stopped at. Only recovery that genuinely runs out of
attempts, or a failure a retry cannot fix (the server rejecting the request),
reaches you as a message.

**One loading affordance.** Every wait — connecting, opening a folder, paging
the library, preparing a session, seeking, buffering, reconnecting — now shows
the same dimmed overlay with a spinner instead of a different spinner per
screen. Short waits stay invisible: the overlay appears only after 250 ms, so a
folder that opens instantly never flashes.

**Gestures claim one control per swipe.** A drag now decides between seek,
brightness, and volume once, after a short travel, and holds it until you lift
your finger. Swiping up for brightness and drifting sideways can no longer trip
an accidental seek.

**Autoplay skips finished files.** After a video ends, the jump to the next file
in the folder passes over anything already at 100% — played through or marked
watched by long-press — for both server and local sources.

**Backup and restore (Settings → Backup).** Export writes the connection
details, playback and player settings, recent files, and the full watch history
to a JSON file you choose the location for; import reads it back. The file is
grouped, pretty-printed, and carries a readable timestamp beside every raw one,
so it can be edited by hand or moved to another tablet. Import is forgiving: a
key the file omits keeps what the device already has, and out-of-range values
fall back to defaults rather than corrupting anything.

This release is signed with the same key as v0.15.0 and upgrades over it
normally. Moving from a locally built debug APK still requires an uninstall,
because debug and release signatures differ — export your data first.
